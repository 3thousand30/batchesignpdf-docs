# Batch eSign PDF documentation

Public documentation for Batch eSign PDF, the local Windows utility for
superimposing a signature image or applying a real USB-token/certificate-store
digital signature to batches of PDF documents.

**Status: not yet published.** Batch eSign PDF itself is currently an
in-development engineering prototype (see `Apps/BeSP/details.md`). This
repository's Pages site should not be made public or linked from the Store
listing until the app has a release candidate.
