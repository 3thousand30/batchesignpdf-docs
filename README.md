# Batch eSign PDF documentation

Public documentation for Batch eSign PDF, the local Windows utility for
superimposing a signature image or applying a real USB-token/certificate-store
digital signature to batches of PDF documents.

**Status: published documentation.** The site is available at
https://3thousand30.github.io/batchesignpdf-docs/.

Batch eSign PDF's superimposed-signature workflow is prepared for its first
release. USB-token signing requires a compatible RSA certificate registered in
the Windows certificate store; physical token and Adobe Acrobat Reader
compatibility validation remain release follow-up work. Do not describe every
USB device or certificate provider as supported until that validation is done.
