# Support

Email [support@3thousand30.com](mailto:support@3thousand30.com).

Include:

- App name and version
- Windows version
- Whether you were in Superimpose or USB Token mode
- For Superimpose mode: target page, anchor position, and signature width
- For USB Token mode: certificate type (software certificate vs. USB/DSC
  token) and the token vendor/driver, if applicable
- Whether the source PDF was already signed, encrypted, or malformed
- The exact error text shown by the app

Never send real signature images you consider sensitive, real certificates,
PIN values, or confidential source PDFs. If a sample is needed, create a
synthetic PDF and use a disposable test signature or certificate.
